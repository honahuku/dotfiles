# tasks のテスト

公開dotfilesのルートで、毎回次のコマンドを実行する。`bin/`の既存テストと`tests/`の単独CLIテストをまとめて収集する。

```sh
# 実データを使わず、全ケースを同じ条件で検証する。
uv run --with pytest pytest .
```

`uv`がpytestを実行環境に用意する。テストファイルやケースの指定、フィルタ、追加オプションは付けない。失敗を修正した後も、同じコマンドで全件を再実行する。

テストは `CLAUDE_COMPANION_STORE` を pytest の一時ディレクトリへ向ける。通常の保存先は使わない。vault バックアップのテストでは一時ディレクトリ内の Git リポジトリとローカルの bare リポジトリを使用する。テストの追加時も、実データや実際の vault、外部リモートへ書き込まないことを確認する。
