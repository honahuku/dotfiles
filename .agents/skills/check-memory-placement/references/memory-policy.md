# 指示とプロファイルの保存先

## 指示・再発防止策

ローカルメモリは端末間で共有されず、指示を確実に読み込む入口にもならないため、Coding Agentsへの指示・禁止事項・手順・再発防止策の保存先にしない。協働方針や判断軸という分類でも、将来の動作を規定する内容は指示として扱う。

- まず担当する既存スキルを選び、規則の詳細をその`references/`に置く。スキル本体から、読む条件と参照先を案内する。
- 常時適用する必要がある、またはスキルの自動選択だけでは読まれないおそれがある規則は、グローバルAGENTS.mdから担当スキル・資料を呼び出す。規則の本文を複製せず、操作前に読む経路を設ける。
- 機械的に判定できる禁止条件は既存hookでも拒否できるようにする。hookを指示本文や読み込み経路の代わりにはしない。
- 既存メモリに同じ指示がある場合も、共有元へ反映し、ローカルメモリへの追記だけで再発防止を完了したと報告しない。

共有元の公開可否と端末への反映確認は、`~/.agents/skills/write-agent-instructions/references/context-policy.md`に従う。worktreeでの編集、共有元への取り込み、端末への適用を区別する。

## メモリ

メモリに記録するのは、本人の特徴・特性・属性・役割など、継続的な支援に必要なプロファイルに限る。個人情報は公開しない。

作業履歴・プロジェクトの決定・参照先は、対象タスクやプロジェクトの既存記録へ置く。本人についての事実と、Coding Agentsが守るべき指示が混在する場合は、プロファイルと担当スキルの規則に分ける。
