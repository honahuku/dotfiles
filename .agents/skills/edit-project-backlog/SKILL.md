# プロジェクトのバックログを起票・更新する

対象: $ARGUMENTS

最初に `~/.agents/docs/work/context.md` の `edit-project-backlog` セクションを読み、保存先・分類基準・権限・手順を確認する。この資料がなければ、組織固有の値を推測せず、不足を伝えて停止する。

既存カードを読んでから編集し、リンク・過去の判断・記録を保持する。関連PRや資料ですでに説明済みの内容は参照し、カードには判断に不足する情報を残す。外部サービスへの反映は、依頼で許可された操作に限る。反映後に再取得して検証する。
