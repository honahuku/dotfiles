# カードの修復

派生カードを修復するか、難しい原問題に補助カードを追加する。

## 原問題は変更しない

理解や想起が難しいカードが`verbatim_mcq`なら、問題、選択肢、公式解答、公式解説は編集しない。ひっかけや不自然な過去問もそのまま残す。失敗を診断し、有用なら想起・区別用の派生カードを別に追加する。原問題は試験形式の練習用として保つ。

## 診断

- `concept_confusion`: 関連概念を取り違える。必要なら区別カードを一枚追加する。
- `knowledge_gap`: 原問題は妥当だが、基礎となる規則を理解していない。原問題を保持し、簡単な想起カードを一枚追加する。
- `rote_question_memory`: 選択肢の位置だけを覚えている。原問題を保持し、必要なら選択肢の手掛かりなしに規則を問うカードを追加する。
- `too_broad`・`too_long`・`ambiguous_prompt`・`multiple_facts`・`missing_context`: 派生カードに適用する。必要に応じて書き換え・分割する。

## 出力

項目ごとに診断、カード種別（`verbatim_mcq`・`generated`）、元カードの扱い、補助または置換カード、理由を返す。追加不要なら補助欄は「なし」にする。`verbatim_mcq`の元カードは通常、変更せず保持する。
