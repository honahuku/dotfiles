# 試験日と過去問の収録範囲

原文保持の過去問デッキでは、各回の問題を削ったり書き換えたりせず、どの試験回をAnkiへ取り込むかで範囲を調整する。

## 未使用の試験回を残す

複数回の過去問があり、実施順を確認できる場合は次のように扱う。

- 可能なら最新回を最終確認用に未使用のまま残す。
- さらに直近の一回または二回を検証用にする。
- それより前の比較的新しい回から最初の学習デッキを作る。
- 検証用の回は本番と同じ条件で受験し、採点結果を記録してからAnkiへ追加する。
- ユーザーがその回を使用すると決めるまで、派生カード経由でも未使用問題を見せない。

四半期ごとの試験回が多くある場合は、最新より少し前の複数回を学習用、その次の新しい一回または二回を検証用、最新を最終確認用にする。日付や順序が不明なら確認し、最新回を推測しない。

## 残り30日以上

広い練習範囲と長期定着を目指す。資料があれば学習用の約三回分から始め、使用を決めた回は全問を収録する。さらに古い回でも有用な弱点が見つかるなら追加する。検証用・最終確認用は未使用に保ち、派生カードは既定では作らない。

## 残り14〜29日

原文を保ち、新規に使用する回数を抑える。最初は学習用の二回から三回を優先し、学習がある程度安定してから検証用の回を使用する。派生カードは繰り返す知識不足に限る。

## 残り7〜13日

測定と弱点修復を優先する。古い回を大量に追加せず、まだ使っていない最近の回を時間制限付きの検証・模試に使う。採点後に原文の問題を取り込み、少数の派生カードで弱点を補う。

## 残り0〜6日

新規資料で学習を圧迫しない。過去の大量資料を新たに使用せず、既存の過去問と理解や想起が難しい補助カードを復習する。結果から学ぶ時間が残る場合だけ未使用回を使い、それ以外は既知の弱点を復習して自信を保つ。

## 古い回の追加を止める基準

総回数の上限を先に決めず、追加によって得られる学習価値を見る。新しい一回がほぼ既習概念の反復で、新たな弱点がほとんど出なければ、それ以上古い回を追加しない。

枚数を減らすために原文を書き換えない。試験回全体の使用を控えるか、不要な派生カードを作らないことで範囲を減らす。
