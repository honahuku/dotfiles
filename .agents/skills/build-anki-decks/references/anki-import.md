# Ankiへの取り込み

専用のカスタムノートタイプを使い、未知のノートタイプや既定のノートタイプへそのまま取り込まない。

## ノートタイプ

個人情報保護士では、通常フィールドを次の順で作る。

`Question`、`Option1`、`Option2`、`Option3`、`Option4`、`CorrectOptionIndex`、`OfficialAnswer`、`OfficialExplanation`、`Source`、`Topic`、`Priority`、`NeedsReview`

`Tags`は通常フィールドではなくAnkiのタグ列にする。明示的な変更依頼がなければ、付属の表面・裏面テンプレートを変更しない。

## 取り込み設定

取り込み前に次を設定・確認する。

- 区切りはカンマ、引用符はCSVの二重引用符、文字コードはUTF-8。
- ファイル先頭に`#separator:Comma`、`#html:true`、`#columns:...`、`#tags column:13`がある。
- 先頭のデータ行に`"Question","Option1",...`のような通常ヘッダーがない。
- `#tags column:13`によって`Tags`がAnkiのタグへ対応する。
- 初回は新しいノートを作る。
- 再取り込みは対象原本全体で`Question`が一意の場合だけ既存ノートを更新する。それ以外は安定した識別キーを確認するまで止める。
- 選んだ重複処理を出力のメタデータに記録する。

取り込みプレビューを使う。問題文、複数行の解説、空の選択肢、タグが意図したフィールドに出なければ停止する。

## 取り込み後の照合

初回は取り込んだノート数と出力した`ready`記録数を照合する。再取り込みは前回のノート数と比較し、想定した既存ノートが更新されたことを確認する。

複数行問題、引用符を含むフィールド、空の`Option4`、`NeedsReview=false`、空でないタグについて、存在する分類ごとに原本順の最初の記録を選ぶ。存在しない分類は存在しないと記録し、架空の確認例を作らない。

- 表面に問題と空でない選択肢だけが表示される。
- 裏面に公式解答と解説全文が表示される。
- 改行と日本語の句読点が読める。
- HTML特殊文字が文字として表示され、マークアップにならない。
- タグが通常フィールドではなくAnkiのタグ一覧に表示される。
- 明示的に受け入れられていない`NeedsReview=true`が学習デッキに入っていない。
