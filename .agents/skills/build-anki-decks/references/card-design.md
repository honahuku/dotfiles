# 派生カードの設計

この規則はLLMが作る補助カードだけに適用する。過去問を書き換える許可にはしない。

## 原則

1. 一枚で思い出す対象を一つにする。
2. 表面は意図した答えが一つに定まる具体性を持たせる。
3. 裏面は簡潔にし、原本に根拠を持たせる。
4. 知識を抽出するときも原本の用語を保つ。
5. 生成したカードであることを明示する。
6. 生成文を試験の原文として示さない。
7. 年、日付、条文番号、個数、穴埋め番号など、生成フィールド内の数字はすべてASCII半角数字`0`〜`9`にする。

数字の正規化は派生カードだけに適用する。原文保持の過去問では数字の文字種も原本どおりにする。

## 種類

- 想起カード: 定義、規則、基準、役割、閾値、式、直接的な関係を問う。`recall`を使う。
- 区別カード: 原本から関連する概念の混同が確認できる場合に使う。`distinction`を使う。

## 原問題との関係

元の過去問カードは変更せず、簡単な派生問題へ置き換えない。明示依頼があるか、修復で必要な場合だけ補助カードを追加する。CSV・デッキは過去問と分ける。試験に関連する派生カードには`第<回>回個人情報保護士 generated`を付ける。課題が明示されていれば`generated`の前に`課題I`または`課題II`を入れる。
