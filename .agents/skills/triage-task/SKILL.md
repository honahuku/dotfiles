# タスクの利用者価値、費用、責任範囲、既存手段との重複から、着手可否と優先順位を判断する

対象: $ARGUMENTS

最初に対象チームの目標・分類基準・判断権限を確認する。不明な組織固有の値は推測せず、ユーザーに確認してから進める。

タスクの根拠資料を読み、既存の仕組みで目的を達成できるか、利用者の負担を減らせるか、維持費と責任範囲が妥当かを評価する。複数のタスクでは全体の偏りや統合候補を先に示し、個別の判断と根拠を続ける。
