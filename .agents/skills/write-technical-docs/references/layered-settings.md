# 設定が複数レイヤーにまたがるとき

似た役割に見える設定が複数ある場合（例: Kubernetes 側のタイムアウトと Load Balancer 側のタイムアウト）、読み手は「なぜ両方要るのか」で必ず止まる。この疑問を放置しない。

- 各設定が**どのレイヤーの設定か**（K8s / LB / アプリなど）を明示する
- **なぜ役割分担として複数必要か**を説明する。名前や単位が似ていても、制御する対象・タイミングが違うから両方要る、という理由を書く
- 複数の設定の関係が条件式（`A >= B + C` 等）で表せる場合、その式を一次情報で確認したうえで明記する。式を示さずに「うまく設定してください」で終わらせない
