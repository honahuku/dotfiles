# 実験結果を脚注で引用する

対照実験・検証レポートの結果を要約したドキュメント（ADR・proposal等）で、生データが別リソース（PRのdiff・Notionページ等）にある場合、脚注`[^1]`形式で参照する。文書全体で同じ生データを何度も参照するときは、番号を使い回し、URLごとにインラインリンクを繰り返さない。

- **脚注は具体的な主張・数値に付ける。** 「詳細は〇〇を参照」のような、読み手に別リソースへ移動するよう促すだけの文は書かない。事実を述べた文・具体的な数値のすぐ後に脚注番号を置く
- **「次の通り」の直後には付けない。** 「次の通り。[^1]」は`[^1]`が「次」を指しているように読める。表・図が続く場合は表・図のキャプション（後述の通し番号）に付け、箇条書きが続く場合は箇条書き中の具体的な事実に付ける
- **「次の通り」は直後に表・図が続く場合だけ使う。** 推測・考察の箇条書きを導入する文では使わない
- **表に通し番号とキャプションを付けている場合は、キャプション側に1つだけ脚注を付ける。** 表内の特定のセルにだけ付けると、なぜそのセルだけ根拠が要るのか読み手が混乱する
- **同じ数値・主張が文書内で繰り返し登場する場合、再掲のたびに脚注を付け直さない。** ただし離れたセクション（読み手がそこだけを読む可能性がある場所）で改めて数値を主張として使うときは、そのセクションでも1回は付ける
