# ディレクトリ図と折りたたみ見出しの書式

## ディレクトリ構成をtreeで書くとき

- **ディレクトリ構成をtree記法で書くときは、ユーザーから特別な指示がない限り必ずディレクトリ優先・アルファベット順にする。** nvim等のファイラーが実際に表示する並びと一致させる
- 読む順・重要度順で見せたい場合も、tree自体の並びは変えない。tree直後の説明文や別のリストで読む順を示す
- 判定条件: tree記法（`├──`/`└──`を使う表現）を書く場面すべてに適用する。対象プロジェクトを問わない


## トグル（`<details><summary>`）の見出しの書き方

トグルを開けば説明・根拠が書かれていることは、読み手にとって自明である。見出しに「〜の根拠」「〜した理由」「〜の詳細」と明示しない。見出しには結論・ルールそのものを言い切りで書く。

- NG: `<summary>閾値を5分間に3件超にした根拠</summary>`
- 良い例: `<summary>閾値は5分間に3件超とする</summary>`
- 判定条件: 見出しから「根拠」「理由」「詳細」を外しても、トグルの中身を読めば同じ情報が伝わるなら、その語は見出しに要らない。見出しはトグルの内容を予告する要約ではなく、トグルが答える結論を先に言い切る
