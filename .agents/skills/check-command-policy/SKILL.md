# コマンドの実行条件を確認する

実行前に`references/command-policy.md`の該当するツールと操作の条件を読む。状態を変える操作では、同資料の「可逆性に基づく操作判断」を適用する。明示された許可を、操作名だけを理由にした禁止で覆さない。適用中の上位指示にある禁止は変更しない。

自動レビューへ実行要求を渡す前は、同資料の「外部の承認レビューへ渡す根拠」に従う。worktree内でも、禁止事項と許可例外の出典・適用条件を実行要求に添える。
