# コード作成とコマンド実行の制約

## 発火条件の注釈

このスキルの適用だけで、依頼範囲を超えたコード作成・実行が許可されるわけではない。新規・既存を問わず、実行前に内容・入力・対象・副作用を確認し、`check-command-policy`の可逆性判断に従う。復旧可能な依頼範囲内の作業は進め、不可逆または影響が不確実な操作だけ具体的な対象と影響を示して許可を得る。


## コマンドの実行直前

読み取り、検索、lint、fmt、検証のコマンド連結には、`check-command-policy`の`references/command-policy.md`「コマンド連結」を適用する。独立した処理は別々のツール呼び出しで並列化する。

片付け・競合解消・設定移行で既存のファイルやリンクを移動する場合は、目的と復旧可能性を確認する。依頼のない独自の退避先は作らない。削除・移動は操作名だけで拒否せず、`check-command-policy`の可逆性判断に従う。

削除の復旧可能性は、実行環境のalias・関数や管理ツールを確認して判断する。不可逆または復旧が不確実な場合は対象・影響を示して明示許可を得る。許可後はCoding Agentsが実行し、事後確認を行う。本人操作が必要な場合は`troubleshoot-environment`の手動依頼手順に従う。
