# コード作成とコマンド実行の制約

## 発火条件の注釈

このスキルは「新規スクリプトを書いてよい」ことを意味しない。AGENTS.mdの絶対禁止（`python`/`node`/`ruby`/`perl`等の汎用言語のコマンド実行禁止、`bash`/`sh`等インタプリタ経由のスクリプトファイル実行の全面禁止）は独立して常時効く。このスキルが発火するのは、ユーザーが明示的に「スクリプトを書いて」「実行して」と指示した場合（例: 実験・検証用ツールの作成依頼）に限る。既存コードの編集はこの制約に触れないため、通常の作業の一部として発火する。


## コマンドの実行直前

読み取り、検索、lint、fmt、検証を含め、各`exec_command`の`cmd`が単一コマンドであることを確認する。`|`・`;`・`&&`でつながない。検索結果の絞り込みは別のコマンドかツール内の値処理で行い、独立したコマンドは別々のツール呼び出しで並列化する。

片付け・競合解消・設定移行で既存のファイルやリンクを移動しようとしている場合は、削除の代替として退避しようとしていないか確認する。その場合は実行せず、共通指示に従って手動実行用の`rm`コマンドを提示する。ユーザーが明示的に依頼した移動・改名と、Coding Agentsが独自に選んだ退避を区別する。

削除依頼ではファイル・ディレクトリとも`rm`を使い、本人のtrash aliasを迂回する絶対パス指定・`rmdir`などに置き換えない。許可された確認・準備はCoding Agentsが実行して結果を示し、未実行の本人操作とはコードブロックを分ける。完了報告後の検証もCoding Agentsが行う。詳細は`troubleshoot-environment`の手動依頼手順に従う。
