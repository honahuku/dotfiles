# 参考文献・出典の探し方

知見・主張の根拠として文献を示すときのルール。

- 次の優先順位で探す。上の段で見つかればそこでやめる。下の段に進むのは、上の段で適切なものが見つからなかったときだけ
  1. 日本語の査読付き文献で DOI があるもの
  2. 英語の査読付き論文で DOI があるもの
  3. 日本語の査読なし文献で DOI があるもの
  4. 英語の査読なし文献で DOI があるもの
  5. ここまで進んでも見つからない場合は、制約を外して探してよいか依頼者に確認する。勝手に制約なしで探さない
- リンクは可能な限り DOI 形式（`https://doi.org/<DOI>`）で示す。出版社サイト・researchgate・まとめ記事の URL は使わない
- 文献を出典として採用する前に、内容・著者・掲載誌・DOI・査読の有無を確認してから書く。PDF が読めず確定できないものは採用しない（裏取りできた範囲だけ載せる）
