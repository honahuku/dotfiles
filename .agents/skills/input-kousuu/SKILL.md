# 確認済みの活動と勤怠から、対象期間の工数を分類して入力用の表を作る

対象: $ARGUMENTS

最初に保存先・分類基準・権限・手順を確認する。不明な組織固有の値は推測せず、ユーザーに確認してから進める。

活動の実績と予定を区別し、会議は出席を確認できた分だけ計上する。分類ごとの時間を保持し、日ごとの配分は入力先で正と定められた勤務時間に合わせる。活動記録や手元の勤怠ログでその値を補完・上書きせず、対象日も入力先の基準に従う。数値計算はツールで行い、未分類・低確度の項目は確認する。入力案と外部システムへの書き込みは分けて扱う。
