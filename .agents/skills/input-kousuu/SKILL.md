# 確認済みの活動と勤怠から、対象期間の工数を分類して入力用の表を作る

対象: $ARGUMENTS

最初に `~/.agents/docs/work/context.md` の `input-kousuu` セクションを読み、保存先・分類基準・権限・手順を確認する。この資料がなければ、組織固有の値を推測せず、不足を伝えて停止する。

活動の実績と予定を区別し、会議は出席を確認できた分だけ計上する。分類ごとの時間を保持し、日ごとの配分を勤怠の実働時間と照合する。数値計算はツールで行い、未分類・低確度の項目は確認する。入力案と外部システムへの書き込みは分けて扱う。
