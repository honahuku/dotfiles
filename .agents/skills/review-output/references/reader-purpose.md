# 読み手に伝える用件と情報量

文章を書く・直すときと、チャットで応答するときは、読み手に伝える用件を定め、その目的に対して内容と量を整える。読み手の気持ちや隠れた意図を推測して本文に足すことではない。

## 他人に送る文章

送信用の文案は、用件と必要な情報が固まる前に書き始めない。次の順で進める。

1. 読者、伝える目的、読後に期待する反応を特定する。
2. 指定されたリンクや関連資料を調べ、確認できた事実・推測・未確認事項を分ける。
3. 未決の論点が文面の意味や相手に求める判断・行動を左右する場合は、文案作成を止める。追加調査で解消できるなら先に調べ、ユーザーの判断が必要なら利用可能な質問ツールなどで具体的に尋ね、回答が必要な作業は保留する。未決の思考を送信用の文章に移さない。
4. 集めた情報で用件を満たせるかを読み手の立場から判定する。足りなければ調査または質問へ戻る。満たせると判断した後にだけ、文案を作成する。

つぶやきではなく、他人に送る・他人が読むことを想定した文章では、読み手に「把握しておいてほしい」「意見を聞きたい」「アクションを求める」のどれに当たるかを考える。複数に当たる場合は、用件や求める判断・行動を読み分けられる構成にする。どれにも当てはまらない場合は、送る必要があるかをユーザーに確認する。

書き始める前に、次を確認する。

- 誰が読む文章で、読んだあとに何を知り、判断し、行う必要があるか。
- 相談なら、誰に何を判断してほしいか。自分で決められることを相談として相手に預けていないか。
- 共有なら、相手が把握すべき結論や状況は何か。判断を求めているように見せて、実際は共有だけになっていないか。
- 依頼なら、目的、対象、期限、求める作業の範囲が分かり、相手が着手できるか。
- 結論、事実、理由、条件、未確認事項、次の動きのうち、読み手の用件に必要なものが入っているか。

自分の判断で進められる内容は、必要なら判断結果を共有する。相手の意見や合意が必要な内容は、何を一緒に考え、何を決めたいのかを示す。相手に作業を求める場合は、何をどこまでいつまでにしてほしいかを示す。相談・共有・依頼を一つの文面に含めるときは、それぞれの用件が混ざらないように分ける。

## チャット応答

ユーザーへの応答では、質問や依頼に答えること、考えを一緒に整理すること、必要な次の確認や行動を伝えることのどれが求められているかを文脈から判断する。明示された問いにはまず答え、必要な情報を過不足なく添える。用件のない前置き・補足・提案は加えない。応答の目的が定まらず、その違いで回答内容が変わる場合はユーザーに確認する。

他人に送る文章案では、最初に共有・相談・依頼のどれかと、読者に期待する反応を定める。相談で求める判断や依頼する作業が決まっていない場合、その未確定な考えを送信可能な文面に整えて提示しない。まず会話内で、確定した事実・こちらの推奨・未決の判断を分け、必要なら未決の判断を具体的な質問にする。情報共有を選ぶ場合は、結論・背景・影響と、自分が取る次の行動を示す。行動方針を提案するときは、担当・対象・目的・順序を明確にする。

## 読み手側からの見直し

本文を書いた後は、受け手として読み、次を確認する。

- なぜこの文章を受け取ったのか、読み手が推測しなくても分かるか。
- 結局何を知り、考え、判断し、行えばよいかが分かるか。
- 情報不足のために聞き返す必要がないか。反対に、読み解くために必要以上の情報を詰め込んでいないか。
- 書き手が自分の判断や責任を避けるために、経緯や曖昧な表現を先に置いていないか。
- 正しさを保ったまま、論点を検討できる表現になっているか。相手の反応を気にして必要な指摘まで消していないか。

送る必要がない情報を削り、用件に必要な情報は残す。短さそのものを目標にせず、情報が足りなくて読み手が迷う場合も、量が多く読み手が探す場合も整える。内容の正しさ、確実性、書き手の意図は保ち、読み手の感情・動機・受け止め方を根拠なく事実として決めつけない。

## 例

| 用件 | 読み手に渡す内容 |
| --- | --- |
| 共有 | 自分の判断で決めたこと、相手に知ってほしい理由や影響 |
| 相談 | 決めたい論点、自分の見立て、相手に聞きたいこと |
| 依頼 | 目的、対象、期限、求める作業の範囲 |
| 進捗報告 | 完了・未完了の状況、未確認事項、次に動くことと時期 |

「先方からもっと早くと言われました」とだけ伝えると、受け手は状況や自分に求められる対応を推測することになる。確認できている事実と未確認の背景を分け、必要なら「先方は月末までの前倒しを希望しています。対応可否を相談したいです」のように、共有事項と相談内容を明示する。背景を確認できていない場合は、推測を事実のように加えない。
