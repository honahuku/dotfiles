# Anki穴埋めカードの例

## 例

### 定義の例

```text
Text:
{{c1::ピギーバック}}とは、1人の認証で複数人が不正に入室する「共連れ」である。

Extra:
1人の認証で複数人が不正に入室する「共連れ」のこと。フラッパーゲートなどで防止する。

第82回個人情報保護士認定試験
```

### 法令時期の例

```text
Text:
個人情報保護法は、{{c1::2003年5月}}に成立し公布され、2005年4月に全面施行された。

Extra:
個人情報保護法の公布時期を問うカード。施行時期は別カードにする。

第82回個人情報保護士認定試験
```

### 不適切な例

```text
Text:
以下のアからエまでの記述のうち、最も適切なものを1つ選びなさい。
ア. ...
イ. ...
ウ. ...
エ. ...
正解は{{c1::イ}}です。

Extra:
ア　適切。問題82の正解はイ。アはルート化、ウはBYOD、エはCYODの説明。
```

この例は試験形式と全選択肢を残し、正解記号だけを問い、無関係な説明をまとめ、裏面に問題のメタ情報を混ぜている。穴埋めでは用語や事実そのものを問う。
